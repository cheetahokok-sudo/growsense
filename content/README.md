# GrowSense Evidence Library

The knowledge-base engine behind GrowSense's organic, long-term marketing.
Every article is a **structured scientific asset**, not a disposable blog post —
so the same verified citations power the public article, the in-app AI coach,
the graphics, and the social cuts.

## Why this exists

GrowSense's moat is **honesty in a fear-driven category.** Height-supplement
marketing sells anxiety; we sell verified understanding. That only works if the
science is genuinely sourced — which is also what Google's health-content
standards (E-E-A-T) reward. A single fabricated citation, once caught, ends the
trust brand. So the library's first rule is inherited from the coach-library
no-fabrication rule.

## The rule

> A citation is **published only after** its title, authors, journal, year, and
> identifier resolve to a real record. Unverifiable citations are **cut, not
> guessed.** Every load-bearing claim maps to a verified reference in
> `evidence-notes.md`.

## Every article (`GS-00X/`) contains

```
GS-00X/
├── article.md          # the piece, medically reviewed before publish
├── references.md       # Verified block (full + PMID) + Pending block
├── evidence-notes.md   # each claim → verified citation (the audit trail)
└── assets/
    ├── graphics-brief.md      # hero + system + topic graphics (brand-locked)
    ├── instagram-carousel.md  # ~10-slide carousel copy
    └── youtube-script.md      # full explainer script with visual cues
```

## Publishing gate (all must be true)

1. Every cited reference is in the **Verified** block.
2. Every load-bearing claim is mapped in `evidence-notes.md`.
3. A **named pediatric / endocrinology reviewer** has signed off (E-E-A-T).
4. No copy claims a habit *increases height* — habits help a child reach their
   **own** potential; the arc bends over years, not weeks.
5. Thai (and other market) versions use the reviewed translation, Sarabun font.

## Brand guardrails for all assets

- Palette: deep-green `#0E2A20`, accent `#2F6B4F`, measured-blue `#2A5C8A`,
  estimated-gold `#9C7A3D`, red reserved for alerts only.
- Type: Fraunces headings, Inter body, Sarabun for Thai.
- Voice: calm, credible, unvarnished — no fear, no false precision.
- Percentiles are illustrative WHO references; projections are ranges.
